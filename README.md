# 공부 친구 (Study Friends)

친구를 맺은 사람끼리만 쓰는 공부 앱이에요. PHP와 MySQL만 있으면 일반 웹호스팅에 그대로 올릴 수 있어요.

| 기능 | 내용 |
|---|---|
| 로그인 | 아이디·비밀번호, 카카오, 구글. 한 계정에 여러 방법을 연결할 수 있어요 |
| 친구 | 각자 8자리 초대 코드가 있어요(평소엔 가려져 있고 눈 아이콘으로 보기). 친구의 코드를 넣으면 바로 서로 친구가 돼요 |
| 프로필 | 프로필 사진(올리면 256px로 줄여서 저장), 이름, 색 |
| 공유 캘린더 | 내 일정과 친구가 공개한 일정, 공부 계획의 할 일을 한 달 달력에 모아 보여요 |
| 날짜 화면 | 캘린더에서 날짜를 누르면 그날 내 할 일·공부 시간·일정, 그리고 친구별로 펼쳐 보는 진도가 나와요 |
| 공부 계획 | 날짜·과목별 할 일 체크, 여러 줄 한꺼번에 넣기, 친구 진도 보기, 목표 공부 시간 |
| 공동 계획 | 고른 친구들과 같은 할 일 목록을 같이 쓰고 각자 체크해요. 사람별 진도와 공동 목표 시간(모두 합친 공부 시간) |
| 학습 플래너 | 하루 한 장: 10분 칸 타임테이블(공부 타이머 기록이 과목 색으로 저절로 칠해지고 손으로도 칠하기), 오늘 할 일·목표 시간, D-day, 기분·만족도·돌아보기. 주간 보기, 한 달이 한 권이 되는 **플래너 북**(넘겨 보기, PDF로 저장). 나만 보기/친구 공개 |
| 공부 타이머 | 공부를 시작하면 친구 화면에 ‘공부 중’으로 보여요. 최근 7일 공부 시간도 비교해요 |
| 메시지 | 친구와 1:1 대화, 읽음 표시, 이모지, 공부 스티커 12종, 메시지 반응(❤️👍😂😮😢🔥). **그림 이모티콘**(캘린더 친구 12종, `assets/stickers/`에 묶음을 더 넣을 수 있어요). **파일 보내기**(문서·압축·소리 파일, 클립 단추·끌어다 놓기·붙여넣기, 한 개 최대 20MB). 사진·동영상은 보내지 않아요 |
| 친구 등수 | 오늘·이번 주·이번 달의 공부 시간·끝낸 할 일·연속 공부 순위. 나와 내 친구들끼리만 비교해요 |
| 공부 인증 (선택) | 공부를 끝낼 때 사진 한 장과 한 줄 메모를 남길 수 있어요(건너뛰어도 돼요). 기본은 친구 공개, 나만 보기도 가능 |
| 보드 · 공지 | 나와 친구들이 같이 보는 게시판과 댓글. 내 글을 **공지로 고정**하면 친구들 화면 위에 공지 창이 떠요(머리줄을 눌러 접고 펴기, 닫기 가능, 한 사람당 3개까지) |
| 알림 | 종 아이콘(🔔)에 모여요. 친구가 일정 등록·수정("OO님이 일정을 등록했어요 · 12월 3일(목) 14:00 · 도서관 스터디"), 공동 계획 초대·할 일 변경, 메시지, 같이 쓰는 메모·그림판을 **다른 사람이** 고쳤을 때, 내 글 댓글·친구 공지. 혼자 것은 알리지 않고, 종류별로 끌 수 있어요. 앱에서는 휴대폰 알림으로 와요 |
| 메뉴 접기 | 컴퓨터는 왼쪽 메뉴를 아이콘만 남게, 휴대폰은 아래 메뉴를 작은 단추로 접을 수 있어요(기기마다 기억해요) |
| 휴대폰 앱 | `app/` 폴더의 Flutter 앱이 사이트를 감싸서 보여 줘요. 만드는 법은 [app/README.md](app/README.md) |
| 그림판 | 친구와 같이 그려요. 펜·선·화살표·네모·동그라미·글자·포스트잇, 옮기기·지우기, 모눈, 마인드맵·순서도·비교 템플릿 |
| 메모장 | 같이 고치는 메모. 동시에 고치면 알려 주고 어느 쪽을 남길지 고를 수 있어요 |

**친구 목록은 각자 비밀이에요.** 다른 사람의 친구는 보이지 않고, 나와 친구가 아닌 사람의 댓글·메모 수정자 이름도 보이지 않아요.

일정, 계획, 그림판, 메모마다 공개 범위를 **나만 보기 / 친구 모두 / 고른 친구만** 중에서 정해요. 친구가 아닌 사람에게는 아무것도 보이지 않아요. 친구를 끊으면 그 사람은 바로 내 것을 볼 수 없어요.

---

## 1. 필요한 것

- PHP **7.4 이상** (8.x 권장), 확장 `pdo_mysql`, `curl`, `mbstring` (대부분의 호스팅에 기본으로 있어요)
- MySQL 5.7+ 또는 MariaDB 10.3+
- HTTPS 주소. 카카오·구글 로그인과 로그인 유지 쿠키에 필요해요

## 2. 설치

1. **데이터베이스 준비**
   호스팅에서 받은 MySQL DB 정보(주소, 이름, 아이디, 비밀번호)를 확인해 두세요. 표는 4단계의 점검 페이지에서 버튼 하나로 만들 수 있어요. phpMyAdmin이 있다면 `schema.sql`을 직접 가져오기(Import)해도 돼요.

2. **설정 파일 만들기**
   `config.sample.php`를 복사해서 이름을 `config.php`로 바꾸고 다음을 채우세요.
   - `app_url`: 앱을 올린 주소 (끝에 `/` 없이). 예: `https://example.com/study`
     이 값이 실제 주소와 다르면 로그인이 유지되지 않으니 꼭 맞춰 주세요.
   - `db`: 호스팅에서 받은 DB 주소, 이름, 아이디, 비밀번호

3. **파일 올리기**
   폴더 안의 파일을 모두 FTP로 올리세요. `sessions/` 폴더는 PHP가 쓸 수 있어야 해요. 대부분 그대로 되고, 안 되면 권한을 700으로 바꾸세요.

4. `https://내주소/check.php`를 열어 점검하세요. 표가 없으면 **표 만들기** 버튼을 누르세요. 빨간 항목을 고치고, 모두 초록색이 되면 `check.php`를 지우세요.

5. 주소를 열고 **회원가입** → 친구에게 내 초대 코드를 알려 주면 끝이에요.

> 모르는 사람의 가입을 막고 싶으면, 친구들이 가입한 뒤 `config.php`의 `allow_register`를 `false`로 바꾸세요.

## 2-1. 새 버전으로 업데이트하기 (이미 설치한 경우)

1. 새 파일을 FTP로 **덮어쓰기**해서 올려요. 이때 **`config.php`는 올리지 마세요**(서버에 있는 내 설정이 지워져요). `sessions/`, `uploads/` 안의 파일(프로필·기록·인증·메시지 사진과 파일)도 그대로 둬요. `app/`, `.github/` 폴더는 서버에 올릴 필요 없어요.
2. 앱을 한 번 열면 데이터베이스에 새 기능용 표·칸이 **자동으로 추가**돼요. 기존 일정·계획·메시지는 그대로예요.
3. 확인하고 싶으면 `check.php`를 다시 올려서 열어 보세요. "새 버전 업그레이드" 항목에 추가된 내용이 보여요. 확인한 뒤 `check.php`는 지우세요.
4. 사진·파일을 쓰려면 `uploads` 안의 폴더(`avatars`, `journal`, `proofs`, `messages`)에 PHP가 쓸 수 있어야 해요. 사진 올리기가 실패하면 FileZilla에서 `uploads` 폴더 권한을 `755`(안 되면 `707`)로 바꿔 주세요.
5. 화면이 이상하면 브라우저에서 **새로고침(Ctrl+F5)** 한 번 해 주세요.

## 3. 카카오 로그인 켜기 (선택)

1. https://developers.kakao.com → 내 애플리케이션 → 애플리케이션 추가
2. **앱 키 → REST API 키**를 복사해서 `config.php`의 `kakao.rest_api_key`에 넣기
3. **카카오 로그인 → 활성화 설정 ON**
4. **카카오 로그인 → Redirect URI**에 `https://내주소/oauth/kakao.php` 등록 (`app_url` + `/oauth/kakao.php`)
5. **카카오 로그인 → 동의항목**에서 **닉네임**을 ‘필수’ 또는 ‘선택’으로 설정
6. **플랫폼 → Web**에 사이트 도메인 등록
7. (선택) **보안 → Client Secret**을 ‘사용함’으로 했다면 그 값을 `kakao.client_secret`에 넣기

## 4. 구글 로그인 켜기 (선택)

1. https://console.cloud.google.com → 프로젝트 만들기
2. **API 및 서비스 → OAuth 동의 화면** 설정 (외부, 앱 이름 입력). 테스트 중일 때는 ‘테스트 사용자’에 친구들의 구글 계정을 추가해야 로그인할 수 있어요
3. **사용자 인증 정보 → 사용자 인증 정보 만들기 → OAuth 클라이언트 ID → 웹 애플리케이션**
4. **승인된 리디렉션 URI**에 `https://내주소/oauth/google.php` 등록
5. 클라이언트 ID와 보안 비밀을 `config.php`의 `google.client_id`, `google.client_secret`에 넣기

카카오나 구글 키를 비워 두면 그 버튼은 화면에 보이지 않아요. 이미 아이디로 가입한 사람은 **설정 → 소셜 로그인 연결**에서 카카오·구글을 연결할 수 있어요.

## 4-1. 휴대폰 푸시 켜기 (선택, 무료)

켜면 앱을 꺼도 카톡처럼 몇 초 안에 알림이 와요. 안 켜면 앱이 꺼져 있을 때 최소 15분마다(휴대폰에 따라 더 늦게) 확인해요.

1. https://console.firebase.google.com → **프로젝트 추가** (이름 예: study-friends, Google 애널리틱스는 꺼도 돼요)
2. **Android 앱 추가** → 패키지 이름 `com.chanwlab.study_friends` → 앱 등록 → `google-services.json` 받기
   - 이 파일의 값(프로젝트 ID, 앱 ID, API 키, 발신자 번호)은 공개해도 되는 식별자예요. `app/lib/firebase_config.dart`에 넣어요.
3. 프로젝트 설정(톱니) → **서비스 계정** → **새 비공개 키 생성** → JSON 파일 받기
   - **이 파일은 비밀번호예요.** GitHub에 올리거나 채팅에 붙여 넣지 마세요.
   - 이름을 `fcm-key.json`으로 바꿔 FTP **맨 위 폴더(www 바깥)**에 올려요. 다른 곳에 두려면 `config.php`에 `'fcm_key' => '/경로/fcm-key.json'`
4. `check.php`에서 "휴대폰 푸시: 켜짐"이 나오면 끝 (확인 후 check.php는 지우기)
5. 새 APK를 받아 설치하고 로그인하면 이 휴대폰이 푸시를 받기 시작해요

Firebase 푸시(FCM)는 보내는 양에 상관없이 무료예요. 카드 등록도 필요 없어요.

**아이폰(홈 화면 웹앱)·컴퓨터 브라우저 푸시** — 사이트가 **https**일 때만 돼요.
1. Firebase 프로젝트 설정 → 일반 → **웹 앱 추가**(</> 아이콘) → 나오는 `apiKey`, `appId`, `projectId`, `messagingSenderId`
2. 프로젝트 설정 → 클라우드 메시징 → **웹 푸시 인증서 → 키 쌍 생성** → 공개 키(vapidKey)
3. 서버의 `config.php`에 `'firebase_web' => [...]`로 넣기 (`config.sample.php` 참고, 비밀 값 아님)
4. 아이폰: Safari로 사이트 열기 → 공유 → **홈 화면에 추가** → 홈 화면 아이콘으로 열기 → 알림 화면에서 **이 기기에서 푸시 받기 → 켜기** (iOS 16.4 이상)

## 6. 파일 구조

```text
index.html            앱 화면 (한 페이지)
assets/app.css        디자인
assets/js/main.js     시작, 로그인 화면, 메뉴, 화면 전환
assets/js/core.js     서버 요청, 공통 조각 (공개 범위 고르기 등)
assets/js/views/      화면별 코드 (calendar, study, messages, board, draw, notes, friends, settings, more)
api.php               모든 서버 기능의 입구 (api.php?a=events.list 처럼 불러요)
handlers/             기능별 서버 코드
lib/                  DB 연결, 로그인, 공개 범위 검사, 카카오·구글 공통 흐름
oauth/kakao.php       카카오 로그인 (Redirect URI)
oauth/google.php      구글 로그인 (리디렉션 URI)
```

## 7. 보안 메모

- 비밀번호는 `password_hash`(bcrypt)로만 저장해요. 로그인은 15분에 같은 아이디 8번, 같은 IP 30번까지만 시도할 수 있어요.
- 모든 쓰기 요청은 CSRF 토큰을 확인하고, 모든 SQL은 prepared statement를 써요.
- 메시지 파일은 정해진 확장자만 받고, 서버에는 무작위 이름의 `.bin`으로 저장해요. 받을 때는 항상 내려받기(attachment)로 보내서 브라우저에서 실행되지 않아요.
- 친구 관계와 공개 범위는 화면이 아니라 서버(`lib/access.php`)에서 매번 검사해요.
- `.htaccess`가 `config.php`, `lib/`, `handlers/`, `sessions/`를 바깥에서 못 열게 막아요. **nginx**처럼 `.htaccess`를 읽지 않는 서버라면 같은 규칙을 서버 설정에 넣거나, `config.php`의 `session_path`를 웹에서 안 보이는 폴더로 바꾸세요.

## 8. 알아 두면 좋은 점

- 새 메시지, 친구 공부 상태, 그림, 메모 변경은 웹소켓 대신 몇 초마다 서버에 물어보는 방식이에요(메시지 3초, 그림판 1.5초, 메모 4초). 공유 호스팅에서도 돌아가지만, 친구가 수십 명 넘게 동시에 쓰면 서버 부담이 커질 수 있어요.
- 메시지 파일 크기는 PHP의 `upload_max_filesize`·`post_max_size`에도 묶여요. 카페24는 보통 2~10MB예요. 앱이 서버 한도를 읽어서 너무 큰 파일은 미리 알려 줘요.
- 캘린더 공휴일은 양력 고정 공휴일만 표시해요. 설날·추석·대체공휴일은 해마다 달라서 넣지 않았어요.
- 공부 시간은 시작한 날짜로 계산하고, 한 번에 최대 16시간까지 인정해요. 끄는 걸 잊어도 16시간이 지나면 자동으로 끝나요.
